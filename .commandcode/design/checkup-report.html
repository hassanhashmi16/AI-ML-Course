P0 - HIGH - MOTION

frontend/src/index.css, .spinner and @keyframes spin: rotational motion runs for the whole run regardless of the user's motion preference.

FIX: gate the animation on prefers-reduced-motion: no-preference; under reduce, keep the work named with a static marker and the elapsed time.
P0 - HIGH - ACCESSIBILITY

The evidence sheet is a dialog without a keyboard model

frontend/src/components/EvidenceDrawer.jsx: role="dialog" and aria-modal="true", but focus never enters, Tab walks the page behind it, Escape does nothing, and focus does not return to the citation.

FIX: move focus in on open, trap Tab, close on Escape, restore focus to the trigger, and set inert on the page while open.
P0 - HIGH - INTERACTION

No first-run state

frontend/src/App.jsx: with no report loaded, the workspace renders nothing. The only affordance is a form in the rail, and saved runs sit below it.

FIX: an empty document that states what a run produces and runs a prepared case in one click.
